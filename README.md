# Pyramid-maker
Simple Pyramid maker program written in C++
---
# How to use:
(first download the repo from either git CLI or by downloading the zip file)
(also first extract the file / navitate to the folder with the files
## Main
- Windows / MacOS: Double-click the file
- Linux: type in the terminal `./main`

## Main.cpp (Compile from source (just 1 file))
- Download gcc & g++ compiler
- compile using `g++ main.cpp` or `g++ main.cpp -o file-name`
- run it `./a.out` or `./file-name`
